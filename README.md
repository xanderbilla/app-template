## Getting Started

Open [**AWS Cognito Testing**](https://template.xanderbilla.com/) with your browser to see the result.
All the changes and associated projects will be documented below (soon).

While using this project, you must include the following environment variables:
- `NEXT_PUBLIC_CLIENT_ID`
- `NEXT_PUBLIC_COGNITO_DOMAIN`
- `NEXT_PUBLIC_AUTHORITY`

## Deploy on AWS

This project is deployed on AWS using Serverless Service called [AWS Cognito](https://aws.amazon.com/cognito).
